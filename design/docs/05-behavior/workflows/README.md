# 🔄 Workflows

> Mô tả các business workflows — luồng xử lý đa bước, thường span qua nhiều services hoặc aggregates.
>
> **Dự án này không dùng thư mục này.** Các luồng nhiều bước đã được đặc tả ở [`../sequences/`](../sequences/) (quẹt thẻ, hết phiên, đồng bộ lịch, kết nối lại, khởi động lại, hết lease) và ở [`../state-machines/`](../state-machines/); quy trình vận hành nhiều bước (dựng phòng máy đầu học kỳ, cài lại máy) nằm ở [`11-operations/deployment.md`](../../11-operations/deployment.md). Viết thêm workflow ở đây sẽ trùng lặp.

## Cách tạo Workflow mới

1. Copy template từ [`../../../_templates/workflow.md`](../../../_templates/workflow.md)
2. Đặt tên file theo format: `WF-XXX-ten-workflow.md`
3. Cập nhật bảng index bên dưới
